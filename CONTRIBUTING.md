# Katkıda Bulunma Rehberi (Contributing Guide)

DataVortex projesine katkıda bulunmak istediğiniz için teşekkür ederiz! Açık kaynak topluluğunun desteği bu projeyi daha ileriye taşımaktadır.

## 🚀 Nasıl Katkı Sağlayabilirsiniz?

1. **Hata Bildirimi (Bug Reports):** Karşılaştığınız hataları veya beklenmeyen davranışları detaylı adımlarla Issue açarak bildirebilirsiniz.
2. **Özellik Önerileri (Feature Requests):** Yeni bir analiz yöntemi, grafik türü veya AutoML modeli önerisi için Issue oluşturabilirsiniz.
3. **Kod Katkısı (Pull Requests):**
   - Depoyu çatallayın (Fork).
   - Yeni bir özellik dalı açın (`git checkout -b feature/harika-ozellik`).
   - Değişikliklerinizi yapın ve test edin.
   - Commit mesajlarınızı açıklayıcı tutun (`git commit -m 'feat: yeni grafik türü eklendi'`).
   - Dalınıza gönderin (`git push origin feature/harika-ozellik`).
   - Bir Pull Request (PR) açın.

## 📜 Lisans

Projeye yapılan tüm katkıların [MIT Lisansı](LICENSE) kapsamında lisanslanacağını kabul etmiş sayılırsınız.
